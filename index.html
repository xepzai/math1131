Vectors
Algebra Ch.1 Introduction to vectors in 2D and 3D

💡 What is a Vector?

Scalar = just a number (e.g. 5)
Vector = number + direction

In 2D: v = (3, 4)
In 3D: v = (1, 2, -3)

⚙️ Vector Operations

+

Addition: add component by component

(1,2,3) + (4,5,6) = (1+4, 2+5, 3+6) = (5,7,9)
×

Scalar Multiplication: multiply every component

3 × (1,2,3) = (3,6,9)
|v|

Length (Magnitude):

|v| = √(x² + y² + z²)
|(3,4)| = √(9+16) = √25 = 5
📝 Worked Example — Find the length & unit vector
Given v = (1, -2, 2), find |v| and the unit vector û.
1

Find the length:

|v| = √(1² + (-2)² + 2²) = √(1+4+4) = √9 = 3
2

Unit vector = vector ÷ its length:

û = (1/3)(1,-2,2) = (1/3, -2/3, 2/3)
3

Check: |û| should = 1

|(1/3,-2/3,2/3)| = √(1/9+4/9+4/9) = √(9/9) = 1 ✓

📐 Parametric Equation of a Line

Key idea: A line = starting point + t × direction
r(t) = a + t·d
a = point on the line
d = direction vector
t = any real number (the parameter)
📝 Example — Line through (1,2,3) in direction (1,0,-1)
r(t) = (1,2,3) + t(1,0,-1)
= (1+t, 2, 3-t)

At t=0: point (1,2,3). At t=1: point (2,2,2). At t=-1: point (0,2,4).

Vector Geometry
Algebra Ch.2 Dot product, cross product, planes

🔵 Dot Product

a · b = a₁b₁ + a₂b₂ + a₃b₃ = |a||b|cos(θ)
Key uses: find angle between vectors, check if perpendicular (dot = 0)
📝 Example — Angle between two vectors
Find the angle between a=(1,0,1) and b=(0,1,1)
1

Compute dot product:

a·b = 1×0 + 0×1 + 1×1 = 1
2

Find magnitudes:

|a| = √(1+0+1) = √2, |b| = √(0+1+1) = √2
3

Use formula:

cos(θ) = 1/(√2·√2) = 1/2 → θ = 60°

❌ Cross Product (3D only)

a × b = | i j k |
| a₁ a₂ a₃ |
| b₁ b₂ b₃ |

Result = vector perpendicular to BOTH a and b
|a × b| = |a||b|sin(θ) = area of parallelogram
📝 Example — Cross Product
(1,0,0) × (0,1,0) = ?
1
i component: (0×0 - 0×1) = 0
j component: -(1×0 - 0×0) = 0
k component: (1×1 - 0×0) = 1
2
Answer = (0, 0, 1) = k direction ✓

🟥 Equation of a Plane

Normal form
n · (r - a) = 0
Cartesian form
ax + by + cz = d
n = normal vector
n = (a, b, c)
📝 Example — Plane through (1,2,3) with normal (1,1,1)
1
n·(r-a) = 0
(1,1,1)·(x-1, y-2, z-3) = 0
2
(x-1) + (y-2) + (z-3) = 0
x + y + z = 6

Complex Numbers
Algebra Ch.3 i, polar form, De Moivre's theorem

💡 The Big Idea

i = √(-1) so i² = -1

Complex number: z = a + bi
a = real part
b = imaginary part
Think of it as a 2D point: plot a on x-axis, b on y-axis (Argand diagram)

⚙️ Arithmetic

+
(3+2i) + (1-i) = 4 + i
×
(2+i)(3-i) = 6 - 2i + 3i - i²
= 6 + i - (-1) = 7 + i
÷

Multiply top & bottom by the conjugate of denominator

1/(2+i) = (2-i)/((2+i)(2-i)) = (2-i)/(4+1) = (2-i)/5

🎯 Polar Form

Modulus
|z| = √(a²+b²)
Argument
θ = arg(z) = atan(b/a)
Polar form
z = r(cos θ + i sin θ)
Euler's formula
z = re^(iθ)

🚀 De Moivre's Theorem

(cos θ + i sin θ)ⁿ = cos(nθ) + i sin(nθ)
📝 Example — Find (1+i)⁸
1

Convert to polar:

|1+i| = √2, θ = π/4
So 1+i = √2 · e^(iπ/4)
2

Apply power:

(1+i)⁸ = (√2)⁸ · e^(i·8·π/4)
= 16 · e^(i·2π)
= 16 · (1 + 0i) = 16

Matrices & Systems
Algebra Ch.4-5 Gaussian elimination, solving Ax=b

💡 What is a Matrix?

A matrix is a grid of numbers.

A = | 1 2 3 | ← row 1
| 4 5 6 | ← row 2

This is a 2×3 matrix (2 rows, 3 columns)

🔄 Gaussian Elimination

Goal: Turn the augmented matrix into row echelon form, then back-substitute
📝 Example — Solve the system
x + 2y = 5
3x + 5y = 12
1

Write augmented matrix:

| 1 2 | 5 |
| 3 5 | 12 |
2

R2 = R2 - 3×R1:

| 1 2 | 5 |
| 0 -1 | -3 |
3

Row 2 gives: -y = -3 → y = 3

y = 3
4

Back substitute into Row 1:

x + 2(3) = 5 → x = -1

⚙️ Matrix Multiplication

Rule: Row of A · Column of B. Number of columns in A must equal rows in B.
| 1 2 | | 5 6 | | 1×5+2×7 1×6+2×8 | | 19 22 |
| 3 4 | × | 7 8 | = | 3×5+4×7 3×6+4×8 | = | 43 50 |
▶️

Limits
Calculus Ch.2

💡 What is a Limit?

Think: "What value does f(x) APPROACH as x gets close to a?"
lim(x→2) x² = 4 (just plug in x=2)
lim(x→0) sin(x)/x = 1 ← this is famous! Can't plug in 0 directly.

📏 Limit Rules

Sum
lim(f+g) = lim(f) + lim(g)
Product
lim(fg) = lim(f)·lim(g)
Quotient
lim(f/g) = lim(f)/lim(g) if lim(g)≠0

♾️ Limits at Infinity

📝 Example — Rational function limit
Find lim(x→∞) (3x²+1)/(x²+2)
1

Divide everything by highest power (x²):

(3 + 1/x²)/(1 + 2/x²)
2

As x→∞, 1/x²→0:

= (3+0)/(1+0) = 3

Continuity & IVT
Calculus Ch.3

💡 Continuity

Simple check: f is continuous at x=a if you can draw it without lifting your pen at that point
Formal: f continuous at a if lim(x→a) f(x) = f(a)

🌉 Intermediate Value Theorem (IVT)

Plain English: If a continuous function goes from negative to positive (or vice versa), it must cross zero somewhere in between
f(a) < 0 < f(b) → ∃c in (a,b) where f(c) = 0
📝 Example — Show a root exists
Show x³ - x - 1 = 0 has a root in [1, 2]
1
f(1) = 1 - 1 - 1 = -1 (negative)
2
f(2) = 8 - 2 - 1 = 5 (positive)
3

f is continuous (polynomial), f(1)<0<f(2), so by IVT there exists c∈(1,2) where f(c)=0 ✓

✅ Self Check — Continuity & IVT

Q1. Does f(x) = x² - 3 have a root in [1, 2]? (Use IVT)

✓ f(1)=-2 < 0, f(2)=1 > 0, f is continuous → root exists in (1,2) which is √3 ≈ 1.73
✗ f(1) = 1-3 = -2 (negative). f(2) = 4-3 = 1 (positive). By IVT, a root exists!

Mean Value Theorem & L'Hôpital's Rule
Calculus Ch.5

📐 Mean Value Theorem (MVT)

Plain English: If you drive 100km in 1 hour, at some moment your speed was exactly 100km/h
∃c ∈ (a,b) such that f'(c) = [f(b)-f(a)] / (b-a)

Requirements: f continuous on [a,b] AND differentiable on (a,b)

🏥 L'Hôpital's Rule

When to use: Limit gives 0/0 or ∞/∞ form
lim(x→a) f(x)/g(x) = lim(x→a) f'(x)/g'(x)
📝 Example
lim(x→0) sin(x)/x — this gives 0/0!
1

Apply L'Hôpital: differentiate top and bottom separately

= lim(x→0) cos(x)/1 = cos(0) = 1

✅ Self Check

Q1. lim(x→0) (e^x - 1)/x using L'Hôpital?

✓ 0/0 form → L'Hôpital: d/dx[eˣ-1] = eˣ, d/dx[x] = 1 → eˣ/1 at x=0 = 1
✗ It's 0/0 at x=0. L'Hôpital: differentiate top & bottom → eˣ/1 → 1

Inverse Functions
Calculus Ch.6

💡 What is an Inverse Function?

If f takes x → y, then f⁻¹ takes y → x
f(x) = 2x → f⁻¹(x) = x/2
f(f⁻¹(x)) = x and f⁻¹(f(x)) = x

-1/√(1-x²)

1/(1+x²)

Curve Sketching
Calculus Ch.7

🗺️ Sketching Checklist

1

Domain: Where is f defined?

2

Intercepts: x-intercepts (f=0), y-intercept (x=0)

3

Symmetry: Even (f(-x)=f(x)), Odd (f(-x)=-f(x))

4

Asymptotes: Vertical (where denominator=0), Horizontal (limit as x→±∞)

5

f': Find where f'=0 (critical points). f'>0 = increasing, f'<0 = decreasing

6

f'': f''>0 = concave up (∪), f''<0 = concave down (∩)

✅ Self Check

Q1. If f'(x) > 0 on (a,b), the function is...

✓ Positive derivative = function going up = increasing
✗ f'(x) > 0 means slope is positive means increasing

Q2. f''(x) < 0 on an interval means the curve is...

✓ f'' < 0 → concave down (∩). f'' > 0 → concave up (∪)
✗ f'' > 0 is concave UP (∪). f'' < 0 is concave DOWN (∩)

Integration
Calculus Ch.8

💡 Key Idea

Integral = Area under the curve (or reverse of differentiation)
Power Rule (∫)
∫ xⁿ dx = xⁿ⁺¹/(n+1) + C
∫ eˣ dx
eˣ + C
∫ sin x dx
-cos x + C
∫ cos x dx
sin x + C
∫ 1/x dx
ln|x| + C
∫ 1/(1+x²) dx
arctan(x) + C

🔄 Integration by Substitution

When to use: You see a function and its derivative inside the integral
📝 Example — ∫ 2x·cos(x²) dx
1

Let u = x². Then du = 2x dx

2
∫ 2x·cos(x²) dx = ∫ cos(u) du
3
= sin(u) + C = sin(x²) + C

🤝 Integration by Parts

∫ u dv = uv - ∫ v du
LIATE rule: Choose u from: Logarithm, Inverse trig, Algebraic, Trig, Exponential
📝 Example — ∫ x·eˣ dx
1

Choose u = x (algebraic), dv = eˣ dx

du = dx, v = eˣ
2
∫ x·eˣ dx = x·eˣ - ∫ eˣ dx = x·eˣ - eˣ + C = eˣ(x-1) + C
